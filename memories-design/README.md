# Memories — Step 1 (light theme, UI only)
- `screens/` — 4 screens (plain HTML + a small ES module each). All data comes from `js/data.js`.
- `js/data.js` — the data layer (mock JSON today, local API later; see `API_CONTRACT.md`). `js/ui.js` holds the formatting helpers.
- `mock/data.json` — generated by `tools/build_mock.py` (dummy photos in `img/full`, thumbs in `img/thumbs`).
- `ds.css` (shared tokens, `theme-light`) + `app.css` (step-1 components). `flow/00_flow.html` is the journey board.
- `./render.sh` serves this folder on 127.0.0.1:8765 and screenshots every PNG. Try `screens/01_empty.html?state=empty`.
